# Little List

A simple to-do list for Windows, built with React, FastAPI, and SQLite. Tasks are stored on your computer.

## Start the app

1. Install Python 3.10 or newer and Node.js.
2. Download this repository as a ZIP and extract it, or clone it with Git.
3. Open the extracted folder and double-click **start.bat**.
4. The first run installs the required packages. When it finishes, the app opens in your browser at http://localhost:5173.
5. Keep the two opened terminal windows running while you use the app. Close them to stop it.

## What you can do

- Add tasks and mark them done or active again.
- Reorder tasks by dragging, or with the up and down arrows.
- Filter tasks by All, To do, and Done.
- Delete a task with its bin button.

Your local database is stored at backend/todos.db. Keep that file to keep your tasks.
